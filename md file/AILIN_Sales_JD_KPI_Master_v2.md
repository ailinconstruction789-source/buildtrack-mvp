# 3. Lead Target

Lead Target ของ Bell / Piwe / Ying / Nook / Field **ต้องเท่ากันทุกคน**

จำนวน Target จริงให้กำหนดหลังจากมี Baseline Funnel เพียงพอ

แนะนำให้ใช้ **Qualified Lead** แทน Raw Lead เพื่อป้องกันการสร้างจำนวน Lead
ที่ไม่มีคุณภาพ

Qualified Lead ควรมีอย่างน้อย:

-   ติดต่อได้
-   มีความสนใจจริง
-   ระบุโครงการ/ความต้องการได้
-   มีข้อมูล Budget หรือ Loan Readiness เบื้องต้น
-   มี Stage
-   มี Next Action
-   มี Next Follow-up Date

# 4. Sales Funnel มาตรฐาน

Lead → ติดต่อได้ → Qualified → นัดชม → Walk-in → Follow-up → จอง → ยื่นสินเชื่อ →
อนุมัติ → โอน

ทุก Opportunity ต้องสามารถตรวจสอบได้ว่า:

-   Customer / Opportunity คือใคร
-   สนใจโครงการและแปลงใด
-   มาจาก Channel / Campaign ใด
-   Owner / Sales คือใคร
-   อยู่ Stage ใด
-   Next Action คืออะไร
-   Next Follow-up เมื่อไร
-   หาก Lost ต้องระบุ Lost Reason

# 6. Stage D --- Lead Follow-up Discipline

บริษัทต้องการวัด **ความพยายามและคุณภาพในการ Follow-up Lead**
ไม่ใช่เพียงจำนวนครั้งที่โทรหรือส่งข้อความ

Sales ไม่ควรปิด Lead ด้วยเหตุผลเพียงว่า "ลูกค้าไม่ตอบ"
โดยไม่มีประวัติความพยายามติดตามที่เพียงพอ

### Follow-up Standard

**Hot Lead** - Follow-up ภายใน 24 ชั่วโมงหลัง Visit - มี Next Action ชัดเจน -
ติดตามต่อเนื่องตามสถานการณ์ของลูกค้า

**Warm Lead** - ต้องมี Next Follow-up Date - Follow-up
ตามเหตุผลที่ลูกค้ายังไม่ตัดสินใจ

**Lead ที่มี Objection** - Follow-up ให้ตรงกับ Objection - เช่น งบประมาณ สินเชื่อ
เงินก้อน ทำเล แบบบ้าน คู่แข่ง หรือผู้ร่วมตัดสินใจ

**Unresponsive Lead** - ต้องมี Attempt Log - บันทึกวัน เวลา ช่องทาง
และผลการติดต่อ - ก่อนเปลี่ยนเป็น Lost / Unresponsive ต้องมีหลักฐานการ Follow-up

### กฎสำคัญ

> Active Lead ทุกคนต้องมี Next Action และ Next Follow-up Date

ห้ามปล่อย Lead ที่ยังมีโอกาสซื้อโดยไม่มี Action ต่อไป

Follow-up / Appointment / Walk-in / Booking / Transfer / Lost Reason /

เป้าหมายคือให้การประเมินสามารถ **ตรวจสอบย้อนหลังได้ ลดการให้คะแนนจากความรู้สึก
