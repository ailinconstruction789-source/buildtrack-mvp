# ต้นแบบบ้านชั้นเดียวสำหรับ BuildTrack

เปิด `preview.html` ในเบราว์เซอร์ได้โดยตรง ไฟล์รวมโค้ดแสดงผลและภาพอ้างอิงไว้ภายใน ไม่ต้องติดตั้ง Blender หรือเปิดเซิร์ฟเวอร์

- `single-storey-prototype.glb`: ตัวบ้านและจุดอ้างอิงทางเข้า/จุดยืน ไม่มีคน พื้นที่รอบบ้าน หรือไฟจัดฉาก
- `preview-isometric.png`, `preview-front.png`: ภาพต้นแบบเทียบกับภาพตัวอย่างที่ฝังอยู่ใน SketchUp
- `model.mjs`: รูปทรงต้นแบบที่แก้ไขต่อได้
- `model-info.json`: จำนวนสามเหลี่ยม ขนาดไฟล์ และพิกัดอ้างอิง

โมเดลนี้สร้างรูปทรงใหม่โดยอ้างอิงไฟล์ `แบบบ้าน/บ้านชั้นเดียว.skp` ไม่ใช่การแปลง geometry ของต้นฉบับโดยตรง สัดส่วนเป็นค่าประมาณสำหรับตรวจรูปลักษณ์ ไม่ใช่แบบก่อสร้างหรือขนาดตัวบ้านที่ยืนยันแล้ว

ด้านหน้าของโมเดลคือ +Z และแกนตั้งคือ +Y จุด `entrance_anchor` กับ `foreman_anchor` อยู่ใต้กลุ่มบ้านเดียวกัน ต้องใช้ world transform ของกลุ่มนี้เมื่อเชื่อมระบบคนเดินจริง

ยังไม่เชื่อมหน้าแผนที่ ข้อมูลแปลง ระบบเส้นทางเดิน หรือความคืบหน้าก่อสร้าง ชื่อกลุ่มชิ้นส่วนในต้นแบบไม่ใช่หลักฐานว่ารองรับการแสดงสถานะก่อสร้างแล้ว ยังไม่ทดสอบประสิทธิภาพหลายหลัง

สร้างไฟล์ใหม่จากโค้ด: รัน `node scratch/house-prototype/build.mjs` จากรากโครงการ
