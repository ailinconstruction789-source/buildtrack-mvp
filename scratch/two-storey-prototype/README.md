# ต้นแบบบ้านสองชั้น

เปิด preview.html ในเบราว์เซอร์ได้โดยตรง ไม่ต้องติดตั้ง Blender หรือเปิดเซิร์ฟเวอร์

โมเดลสร้างใหม่จากรูปลักษณ์ของไฟล์ แบบบ้าน/บ้านสองชั้น.skp โดยอ้างอิงเฉพาะบ้านที่มองเห็น ไม่รวมชิ้นส่วนซ่อนที่อยู่นอกบ้าน สัดส่วนเป็นค่าประมาณ ไม่ใช่แบบก่อสร้าง

ไฟล์ two-storey-prototype.glb มีตัวบ้านและจุด entrance_anchor / foreman_anchor ด้านหน้าคือ +Z แกนตั้ง +Y ไม่รวมคน พื้นที่รอบบ้าน และป้ายประกอบ

ยังไม่เชื่อมข้อมูลแปลง เส้นทางเดิน หรือขั้นก่อสร้างจริง และยังไม่ทดสอบการแสดงหลายหลัง ชื่อกลุ่มเป็นการเตรียมแบ่งองค์ประกอบเท่านั้น

สร้างใหม่โดยรัน node scratch/two-storey-prototype/build.mjs จากรากโครงการ
