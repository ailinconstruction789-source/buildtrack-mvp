## ความสมบูรณ์ของไฟล์และขอบเขตการตรวจ

- เทียบยอดที่มีชื่อและสถานะจากตัวอ่าน workbook กับ XML ของชีตโดยตรงได้ตรงกัน 964 แถว และยืนยัน hidden rows 2–613 มีชื่อครบ 612 แถว
- ตัวอ่าน Artifact Tool เปิดสำเนานี้ไม่ผ่านข้อผิดพลาด XML/relationships; ตัวอ่านอีกชุดเตือน dependency ของ pivot cache จึงตรวจเนื้อหาเซลล์ของแท็บเป้าหมายซ้ำจาก XML โดยไม่แก้หรือส่งออก workbook ใหม่ ไม่อ้างว่าตรวจ pivot/chart ทุกชีตผ่าน
- กฎ dropdown F2:F1223 และ P2:P1223 ในสำเนาอ้าง `#REF!` ต้องตรวจในชีตจริงหากจะซ่อม รอบนี้ไม่แก้กฎหรือสูตร และไม่ใช้ dropdown ที่ขาดเป็นทะเบียนแปลงสำหรับนำเข้า
- ไม่พบ cached cell error ในแถวที่มีชื่อของแท็บเป้าหมาย แต่ไม่ได้คำนวณสูตรทุกชีตใหม่
- ยังไม่ยืนยันว่าชุดนี้ครอบคลุมลูกค้าในฐานเก่าทั้งหมด เพราะไม่มีรหัสร่วม ไม่ได้อ่านข้อมูลลูกค้าจริงในฐานเพื่อจับคู่ และยังต้องตรึงรุ่นล่าสุดก่อนนำเข้าจริง

## ขั้นถัดไป

1. ยืนยันเบอร์ไม่ทราบแล้ว; ยังต้องตรวจตัวบุคคลชื่อซ้ำก่อนรวม และจัดรหัสถาวรโดยมีตารางจับคู่ที่ตรวจรับได้
2. mapping ชื่อ Sales ทั้ง 7 และวันที่ 2 จุดยืนยันแล้ว; เหลือตรวจ binding บัญชีจริง/โครงการ/แปลง และทบทวนข้อมูลขาดที่ระบุไว้ รายการเก่าไม่ทราบคงไม่ทราบ ไม่จำเป็นต้องแต่งข้อมูลให้ผ่าน
3. เตรียม customer/interest/booking manifest ที่แยกประวัติเหตุการณ์และกันนำเข้าซ้ำ พร้อมรายงานรายการพักตรวจ จากนั้นจึงเตรียมเปลี่ยนฐานภายใต้การอนุมัติแยก

ยังไม่รันตัวนำเข้าหรือสร้าง manifest พร้อมเขียนฐานในรอบนี้ เพราะตัวตนลูกค้าและ mapping ยังไม่ยืนยัน ผลตัวเตรียมร่างและการทดสอบล่าสุดดู `sales-sheet-import-review.md`
